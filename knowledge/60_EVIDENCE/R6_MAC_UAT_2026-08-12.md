# R6 Mac UAT — 2026-08-12

## Evidence type
Operator-reported Mac UAT. This record captures exactly what the operator observed; it is not an independently replayed broker session.

## Environment
- macOS MacBook Air operator machine.
- Installed R6 FULL package containing the BTC/USD Crypto PAPER Lab.
- Local timezone reported by conversation context: Colombia / UTC-05.

## Crypto launcher observation
Operator launched:

`ABRIR_CRYPTO_PAPER.command`

Terminal printed:

```text
AUTO-TRADE Crypto PAPER Lab: http://127.0.0.1:8766/
BTC/USD 24/7 read + Capital Safety + local OMS only. Broker POST: DISABLED. LIVE: BLOCKED.
```

### Interpretation
- The launcher reached the Python Crypto Lab server.
- The server successfully bound the intended loopback URL/port and remained running.
- The terminal correctly reported broker POST disabled and LIVE blocked.
- The browser did **not** open automatically for the operator.
- No evidence in this observation indicates a broker write.

### Defect discovered
`UAT-MAC-BROWSER-001`: browser auto-open is not sufficiently reliable on this Mac when relying on Python `webbrowser.open`.

Required correction:
- prefer direct `/usr/bin/open <localhost-url>` on macOS;
- no shell invocation;
- fall back to `webbrowser.open`;
- browser-launch failure must not terminate the localhost server;
- keep printing the URL as deterministic manual fallback.

## Equity/R5 market-clock observation
Operator also reported that opening the R5/equity flow now reports that the market is closed.

### Interpretation
This is consistent with the intended fail-closed equity behavior: the equity path should not fabricate a tradable snapshot when its market-clock/readiness gate says the US-equity market is closed. The observation is useful UAT evidence that the previously confusing market-state behavior is now visible to the operator.

This is not evidence that a broker order was attempted, filled, or qualified.

## Result
- Crypto localhost server launch: **PASS**.
- Automatic browser handoff: **FAIL / defect recorded**.
- Equity market-closed operator feedback: **PASS as expected gating behavior**.
- Crypto broker write: **NOT PERFORMED / NOT AUTHORIZED**.
- LIVE: **BLOCKED**.

This evidence triggered ADR-0009 and the native multi-asset workstream. Crypto remains rehearsal-only until product capability binding, generic pair support, writer ambiguity semantics, protection lifecycle, reconciliation and bounded PAPER canary evidence are certified.
